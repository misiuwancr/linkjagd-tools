# Linknarr

Linknarr ist die deutschsprachige Plattform zum Entdecken und Vergleichen von Websites, KI-Tools und digitalen Anwendungen. Hauptdomain: https://linknarr.com.

Slogan: „Entdecke das Beste im Web.“

Die eigenständige Wortmarke `linknarr.` nutzt geometrische Pfade, Acid-Lime #D0FF28 und einen dunklen Hintergrund. Helle Flächen verwenden die dunkle Wortmarke für ausreichenden Kontrast. SVG-Dateien liegen unter `public/brand`; das Favicon verwendet die Kurzform `l.`. Keine Schriftdatei oder fremde Logo-Lizenz erforderlich.

Linkjagd bleibt die Social-Media-Marke. „Bekannt aus Linkjagd“, die Route `/linkjagd`, Videozuordnungen und Social-Handles bleiben erhalten.

Markenname, Domain und Standardtexte stehen in `site.config.ts`. Ältere Plattformnamen in redaktionellen Daten werden bei der Anzeige normalisiert; bestehende Datensätze werden nicht überschrieben.

Anbieter-Buttons setzen einen aktiven, gültigen Affiliate-Link voraus. Ohne diesen Link bleibt das interne Profil verfügbar; im Admin erscheint „Affiliate-Link fehlt“. Original-URLs dienen nicht als Ersatz.
